# Puku CLI — Issues

Welcome! This repository is the public place to **report bugs**, **request features**, and **flag documentation problems** for Puku CLI.

Puku CLI is an AI-powered coding assistant for your terminal. Use the templates below to help us understand and act on your feedback quickly.

## File an issue

Pick the template that best matches what you want to report. You'll be guided through the right questions for each case.

| What you want to do                              | Template                                                                                |
| ------------------------------------------------ | --------------------------------------------------------------------------------------- |
| Report a bug or unexpected behavior              | [Bug Report](https://github.com/puku-sh/puku-cli-issues/issues/new?template=bug_report.yml) |
| Suggest a feature or enhancement                 | [Feature Request](https://github.com/puku-sh/puku-cli-issues/issues/new?template=feature_request.yml) |
| Report a documentation problem                   | [Documentation Issue](https://github.com/puku-sh/puku-cli-issues/issues/new?template=documentation.yml) |

## Before you file

Help us help you:

- **Search first.** Check [existing issues](https://github.com/puku-sh/puku-cli-issues/issues) to avoid duplicates.
- **Use the latest version.** Run `puku --version` and update before filing.
- **One issue per report.** Don't bundle multiple bugs or feature ideas together.
- **Scrub secrets.** Never paste API keys, tokens, passwords, or `.env` contents.

## Support

Looking for help, not a bug report? Visit our [community page](https://puku.sh/community) for chat, forums, and other channels where you can ask questions.

## Security

Found a security vulnerability? **Do not file a public issue.** Please follow the disclosure process in [`SECURITY.md`](./SECURITY.md).
